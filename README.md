# MineRC - Resource Pack

Resource pack del server Minecraft **MineRC** (Survival RPG nello spazio profondo).

Questo repository contiene solo `MineRC.zip`, scaricato automaticamente dai giocatori
quando entrano nel server. Il file viene generato e aggiornato dal repository principale
(privato): non va modificato a mano.

`MineRC-Mondo.zip`: l'aspetto della stagione (blocchi, oggetti, creature, spazio della stazione), mandato solo dalla Survival sopra `MineRC.zip`.

`MineRC-Bedrock.mcpack`: il pack per i giocatori Bedrock (icone dei testi, badge dei gradi, pulsanti dei menu), che Geyser manda a chi entra da Bedrock; `server/Rete.java` lo scarica da qui.
